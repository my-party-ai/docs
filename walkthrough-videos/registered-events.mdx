## What's covered

- Creating a Registered Event and configuring registration settings
- Setting capacity, registration end date, branding (logo and name), and age restriction
- Linking a payment profile for paid tickets
- Creating ticket types (free and paid) with capacity and badge colours
- Opening registration and sharing the registration link
- Reviewing and approving (or declining) registration requests
- Bulk-approving all pending registrants
- Using the registration dashboard — total registrations, revenue, breakdown by ticket type
- Pausing and resuming registration
- Checking in registrants at the event using QR codes on guest tickets
