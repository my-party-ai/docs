Every organization has admins and, usually, managers. The person who creates the organization becomes its first admin automatically.

## Roles at a glance

| | Admin | Manager | Member |
| --- | --- | --- | --- |
| See and manage **every** circle and event | Yes | No | No |
| Manage the circles and events **they create or are assigned to** | Yes | Yes | No |
| Create new circles | Yes | Yes | No |
| Invite admins and managers | Yes | No | No |
| Change organization details, branding and payments | Yes | No | No |
| Join circles, RSVP or register, post and vote | Yes | Yes | Yes |

**Admins** have full access to all circles and events in the organization.

**Managers** can only manage the circles and events they create themselves, or that an admin assigns to them.

## Invite admins and managers

Only admins can invite people to help run the organization.

<Steps>
  <Step title="Open your organization's people settings">
    From your organization, go to the admins and managers section.
  </Step>
  <Step title="Add the people">
    Enter each person's first name and a phone number or email. You can invite several at once.
  </Step>
  <Step title="Choose their role and scope">
    Make them an **admin** for full access, or a **manager**. A manager can be scoped to a single circle or one-off event when you invite them, or assigned later.
  </Step>
  <Step title="Send the invitation">
    They receive an invitation and accept it to join your organization in that role.
  </Step>
</Steps>

<Tip>
  Someone who is already on Fast Party can be assigned as manager of one or more circles or one-off events directly, without a new invitation.
</Tip>

## Assign a manager to more circles or events

An admin can give an existing manager more circles or one-off events to run at any time. The manager then sees and manages those alongside the ones they created.

## Remove an admin or manager

Admins can remove another admin or a manager from the organization.

<Note>
  A person can belong to only one organization at a time. If someone you invite already belongs to another organization, they need to exit it before they can accept.
</Note>

## Leaving an organization

An admin or manager can leave the organization themselves. If they're the last person responsible for something, they'll be asked to hand it over first.
