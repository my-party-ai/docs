Inside an organization, members belong to **circles**, and most events happen inside a circle. Events that belong to the whole organization rather than one circle are **standalone events**.

## Create a circle

Admins and managers can create circles in the organization. A manager automatically manages the circles they create.

<Steps>
  <Step title="Name the circle">
    Give it a clear name of up to 30 characters, such as `Batch of 2010`, `Golf Section` or `Hyderabad Chapter`.
  </Step>
  <Step title="Add a description and image">
    Both are optional. The image helps members spot the circle quickly.
  </Step>
  <Step title="Set who it's managed by">
    The name shown as the circle's manager. It defaults to the circle's name.
  </Step>
  <Step title="Invite members">
    Add each member's first name and a phone number or email. They receive an invitation to join.
  </Step>
</Steps>

An admin can assign other managers to the circle at any time. [Admins and managers →](/organizations/admins-and-managers)

### Bring in a circle you already have

If you already run a personal circle, you can link it to your organization so it appears alongside the rest. You need to be the circle's organizer and an admin or manager in the organization. You can also unlink it later.

## Create events inside a circle

From a circle, create any of the three event types:

| Type | Use it when |
| --- | --- |
| [**RSVP Event**](/private-events/event-creation) | You invite specific people and want to know who's coming. |
| [**Registered Event**](/public-events/overview) | People sign up through a link, with or without your approval, and may pay for tickets. You set the capacity when you create it. |
| [**Open Event**](/events/open-events) | Everyone in the circle is welcome, with no RSVP needed. Open Events are shared only with the circle's members. |

Events in an organization's circles belong to the organization automatically. They work exactly like any other event: you set them up on the Event Page, switch on the tools you need, and run them from the Event Dashboard.

## Create a standalone event

Some events belong to the whole organization rather than one circle: an annual gala, Foundation Day or an AGM. Create these as **standalone events** from your organization. They can be RSVP or Registered Events.

An admin can assign a manager to run a standalone event, just like a circle.

## Keep circles active between events

Every circle has a feed where you can share **posts**, run quick **polls**, and send **surveys**. Surveys are drafted for you from a short description of what you want to ask. You review and edit the questions, then publish when you're happy. [Circles →](/recurring-events/overview)
