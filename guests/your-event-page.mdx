Your event page has everything for the event: the details, the host's tools, and the host's updates. Check it now and then as the event gets closer. Tools get added and updated along the way.

## The event tools

The tools sit below the event details, in the order you'll need them as the event gets closer. Tap a tool to open it.

{/* Screenshot to add: images/guests/event-tools.png — The event tools: Event Schedule, Event Lineup and Event Folder open to view; Guest Preferences marked Action needed; Travel & Stay marked Done */}

Each tool shows one of three things:

| On the tool | What it means | What to do |
|---|---|---|
| No label | It's there for you to look at. Event Schedule, Event Lineup and Event Folder work this way. | Open it whenever you like. |
| **Action needed** | The host has asked you for something, like your food choices or travel details. | Open it and fill it in. |
| **Done** | You've given the host what they asked for. | Nothing. You can open it again to make changes. |

Once you fill a tool in, its label changes from **Action needed** to **Done**.

### What each tool is for

| Tool | What it's for | Who sees it |
|---|---|---|
| Event Schedule | What happens when, from start to finish | Everyone invited |
| Event Lineup | Who's speaking or performing, and when | Everyone invited |
| Event Folder | Files the host has shared with you, like menus, maps or tickets | Everyone invited |
| Gifting & Best Wishes | Send the host a gift or a message | Everyone invited |
| Photos | Pictures from the event, shared by the host | Everyone invited |
| Guest Preferences | Tell the host what you'd like to eat and drink | Guests who are coming |
| Travel & Stay | Give the host your arrival, hotel and pickup details | Guests who are coming |
| Potluck Manager | Pick what you'll bring, so nobody brings the same thing | Guests who are coming |
| Tasks | Tasks the host has given you | Guests who are coming |
| Real-Time Guest ETA | Let the host know you're on the way, if you choose to share | Guests who are coming |
| Check-In | Check yourself in when you arrive. It opens on the day. | Guests who are coming |
| Feedback Corner | Tell the host how it went | Guests who are coming |

The host chooses which tools to turn on, so you'll only see the ones they've set up for this event.

"Guests who are coming" means you replied **Yes** or **Maybe** to an RSVP event, or you're registered for a Registration event. If the host approves registrations, you need to be approved first.

## Host updates

The host's updates are **at the bottom of the event page**. They cover changes to the plan, reminders, and anything else the host wants everyone to know. Scroll down to read them.

{/* Screenshot to add: images/guests/host-updates.png — Host updates at the bottom of the event page */}

<Tip>
Everyone invited can see host updates, even if you haven't replied yet or replied No.
</Tip>

## Questions

<AccordionGroup>
  <Accordion title="I don't see a tool someone else mentioned">
    The host may not have turned it on. Some tools also only appear once you've replied Yes or Maybe, or once you're registered.
  </Accordion>
  <Accordion title="Can I change something after it says Done?">
    Yes. Open the tool and update it.
  </Accordion>
  <Accordion title="What do I need to do right now?">
    Look for tools marked **Action needed**. You can also tap **Ask Antsy** and ask "What do I need to do?"
  </Accordion>
</AccordionGroup>
