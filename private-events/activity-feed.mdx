The Event Activity Feed is a real-time group chat and event feed shared by all event participants — hosts, co-hosts, and guests. It keeps everyone connected before, during, and after the event.

## What you can do

- **Post messages** — write a message and share it with everyone on the event.
- **Attach media** — attach images or PDF files to your post.
- **Share GIFs** — pick a GIF from the built-in GIF picker to add some fun.
- **Reply to messages** — reply to any post to keep conversations threaded.
- **React with emoji** — add emoji reactions to any message.
- **Delete or edit your own messages** — update or remove anything you've posted.

## Who can post

All event participants can post in the Activity Feed — hosts, co-hosts, and guests alike. It's a shared space for the whole group.

## Content moderation

The Activity Feed has a built-in content filter. Inappropriate language is blocked before it's posted, keeping the feed friendly for everyone.

## System messages

Alongside user posts, the feed includes automatic system messages that record key event activity — for example, when a guest RSVPs, when the agenda is published, or when the potluck is updated. You can filter to show only system messages if you want a clean event log.

<Tip>
  Use the Activity Feed in the days leading up to your event to share reminders, build excitement, or answer questions — without sending individual emails.
</Tip>
