An **RSVP Event** gives you full control of the guest list. Invited guests receive a personal link and reply Yes, No or Maybe. There's no registration queue and no approval step.

## Create the event

From your Home page, click **Create Event** under **My Events**.

| Field | What to enter |
| --- | --- |
| **Event template** | The invitation card on the left. Click the pencil to pick one from the template store or upload your own. |
| **Banner** | The wide image on the right. Click **Add banner**. |
| **Event Type** | Required. Choose **RSVP Event**. |
| **Event Name** | Required, up to 22 characters. Keep it short: it's what guests see on their invitation. |
| **Description** | Optional, up to 500 characters. What the event is and why people should come. |
| **Event Start Date** | When the event begins. Leave it blank for now if you haven't decided. |
| **Event End Date** | Optional. Set a later day to make it a multi-day event, with its own invitation template for each day (up to 5). |
| **Venue** | Search for the place. Fast Party finds it on Google Maps and adds a **Get Direction** button for guests. |
| **Hosted By** | Required. The name guests see as the host: you, your family, or your organization. |
| **Co-host** | Optional. Add people who help you run the event. |
| **Links** | Optional, up to 3. Buttons such as directions, a dress code or a wedding website. [Event Links →](/private-events/event-links) |

Click **Create Event**. Your Event Page is ready.

## Pick an invitation template

Click the pencil on the event template to open the template store. Search, or browse by category: Gathering, Party, Celebration, Festival, Corporate, Meetup, Family, Night, Outdoors and Kids. Or click **Upload From Device** to use your own design.

## Your Event Page

Once the event is created, you land on its **Event Page**. This is where you set everything up, and it's what your guests see.

<Frame>
  <img
    src="/images/ev-event-page-1.png"

    title="Ev Event Page 1"
  />
</Frame>

| Part of the page | What it's for |
| --- | --- |
| **Template and banner** | The first thing guests see. |
| **Invite** | Add guests and share the invite link. [Guests & RSVPs →](/private-events/guests-rsvp) |
| **Dashboard** | Run the event once invitations are out. [Event Dashboard →](/private-events/event-dashboard) |
| **Post Update** | Post news to every guest on the event wall. [The event wall →](/notifications/event-wall) |
| **Event details** | Date, venue with directions, host and description. The **⋮** menu edits or deletes the event. |
| **Tools** | The [event tools](/events/event-tools) you can switch on. Tools in use are marked **Active**. |

## Edit or delete the event

Open the **⋮** menu next to the event name to edit any detail at any time. If you change the date, time or venue after invitations have gone out, Fast Party offers to notify your guests with an [Alert](/notifications/message-types#alert).

Deleting an event is permanent: guest data, schedules, tasks and everything else on the event are removed. If guests were already invited, they're told the event has been canceled.
