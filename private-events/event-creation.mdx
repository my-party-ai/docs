An **RSVP Event** gives you full control of the guest list. Invited guests receive a personal link and RSVP directly. There's no registration queue and no approval step.

## Creating an event

Click **New Event** from your dashboard and choose **RSVP Event** as the event type. Fill in the required fields to get started. You can always edit them later.

**Event Template and Banner**

Your event template (the invitation card) and banner are the first thing guests see, so don't skip them. Pick a template from the template store or upload your own, and add a wide banner. Any event can run over several days, and each day can have its own template, up to 5 per event. [Sizes and tips →](/events/banner-and-templates)

**Event Type**

Required. Select **RSVP Event**.

**Event Name**

Required. Give it a name your guests will recognize.

**Description**

Optional. Describe the event you're hosting.

**Event Start Date**

Required. When the event begins. You can set it to **TBD (To Be Decided)** if you're not sure yet.

**Event End Date**

Optional. When the event ends. You can set it to **TBD** if you're not sure. Set an end date on a later day to make it a multi-day event, with a schedule spread across the days and its own invitation template for each day (up to 5).

**Venue**

Optional. An address, venue name, or "TBD." Fast Party looks the location up on Google Maps. You can also add details such as a landmark, floor number, or instructions for guests arriving at the venue.

**Hosted By**

Required. Defaults to your name as the host. You can change it to an organization's name, or to someone else's if you're hosting on their behalf. Guests see this on the event.

**Add Links**

Optional. Add buttons with links guests will find helpful, such as directions, a dress code page, or an event website.

Click **Save** to save your event.

You can edit every event field at any time from the event settings page. If you change the date or time after invitations have gone out, Fast Party offers to notify your guests.

## Deleting an event

To delete an event, open the menu (the three dots) in the top-right corner of the event page and select **Delete event**. If guests have already received invitations, they're notified that the event has been canceled.

</Warning>
