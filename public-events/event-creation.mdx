A **Registered Event** in Fast Party lets you open a registration link. Instead of sending personal invitations, you open a registration link. Guests submit a registration request and you approve or decline each one before they're confirmed.

<Tip>
  Use Registered Events for ticketed gatherings, events with limited capacity, corporate events, or any situation where you want to vet attendees before confirming their spot.
</Tip>

## Creating an event

Click **New Event** from your dashboard and choose **Registered Event** as the event type.

**Available fields:**

| Field | Details |
|-------|---------|
| **Event name** | Required. Give it a name your guests will recognise. |
| **Date** | The date of the event. |
| **Start time** | When the event begins. |
| **End time** | When the event finishes. |
| **Timezone** | Defaults to your profile timezone. |
| **Location** | Optional. An address, venue name, or "TBD." |
| **Hosted By** | Optional. The organiser name shown on the registration page. |
| **Expected guest count** | Helps with planning. |
| **Event description** | Optional. Shown on the registration page. |
| **Cover image** | Optional. Personalise your event. |
| **Co-hosts** | Optional. Add co-hosts by name, email, and phone number. |
| **Links** | Optional. Add up to 3 external links with labels. |
| **Registration capacity** | Required. Choose from 50, 100, 250, 500, 1,000, or 1,000+. |

## What choosing Registered Event unlocks

Selecting Registered Event type gives you access to the full registration setup:

- **Ticket types** — create free or paid tickets with capacity, notes, and badge colours
- **Branding** — add your logo and organiser name to the registration page
- **Age restriction** — require guests to confirm they are 18+
- **Payment profile** — link a payment account to collect ticket revenue
- **Registration end date** — close registrations automatically before the event

See [Registration Management](/public-events/registration-management) for the full setup guide.

## Event status

| Status | What it means |
|--------|--------------|
| **Draft** | Setup in progress. Registration is not yet open. |
| **Confirmed** | The event is live. Share the registration link to open registrations. |
| **Cancelled** | The event is off. Confirmed registrants are notified automatically. |

## Editing an event

All event fields can be edited at any time. If you change the date or time after registration has opened, consider notifying registrants.

<Warning>
  Deleting an event is permanent. All registration data, guest lists, agendas, and tasks will be removed.
</Warning>
