The Event Folder lets you upload and share documents with attendees directly from your event. Upload a programme, speaker bios, venue map, or any other file — and control exactly who can see it.

## Uploading files

Open your event and go to the **Event Folder** tab. Tap **Upload** and select a file from your device.

Supported file types include:
- PDF documents
- Images (JPEG, PNG, and other common formats)
- Other common document types

## Controlling visibility

When you upload a file, choose who can see it:

| Visibility | Who sees the file |
|------------|------------------|
| **All guests** | Every confirmed registrant on the event |
| **Specific guests** | Only the attendees you select |

You can change visibility after uploading — for example, share a speaker briefing with co-hosts first, then open it to all attendees when ready.

## Sharing with specific attendees

<Steps>
  <Step title="Upload the file">
    Go to Event Folder and tap Upload.
  </Step>
  <Step title="Choose Specific guests">
    Select the visibility option and search for the attendees you want to share with.
  </Step>
  <Step title="Save">
    Those attendees can view and download the file from their ticket view.
  </Step>
</Steps>

## Deleting documents

To remove a file, tap the delete option next to it in the Event Folder. Deleted files are immediately removed and attendees can no longer access them.

<Warning>
  Deleting a file from the Event Folder is permanent.
</Warning>

<Tip>
  Use the Event Folder to share pre-event materials — venue directions, parking info, the event programme, or a speaker schedule — without cluttering the event description.
</Tip>
