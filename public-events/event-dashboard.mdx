The Event Dashboard is a host and co-host only view that gives you a real-time overview of your registered event — registration counts, revenue, attendee activity, and more — all from a single screen.

## Access

The Event Dashboard is available to **hosts and co-hosts only**. Registered attendees cannot access it.

<Note>
  The Event Dashboard is available on desktop and tablet browsers only. It is not accessible on mobile.
</Note>

## Opening the dashboard

From the web app, open your event and navigate to the **Dashboard** view.

## What's on the dashboard

For registered events, the dashboard includes registration-specific metrics alongside general event activity:

- **Registration stats** — total registrations received, approved, pending, and declined
- **Revenue** — total collected from paid ticket sales (if applicable)
- **Ticket breakdown** — registrations by ticket type
- **Event activity** — live feed of what's happening across the event

Use it as your command center in the days before the event and on the day itself — monitor registration approvals, check attendance, and keep an eye on activity without switching between tabs.

<Tip>
  Keep the Event Dashboard open on a second screen during your event to monitor real-time check-ins and activity feed posts while you manage the event floor.
</Tip>
