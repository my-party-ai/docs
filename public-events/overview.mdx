## What's included

Registered Events give you everything you need to run a public or semi-public event:

- **Registration management** — approve, reject, or waitlist registrants
- **Ticketing** — create ticket types and track orders
- **Event links** — shareable registration links for your event page
- **Activity feed** — real-time updates for attendees
- **Attendee check-in** — dedicated check-in flow for registered guests
- **Photos, F&B, Tasks, Gifting** — the same tools available in Regular Events

## How it differs from Regular Events

| Feature | Regular Events | Registered Events |
|---------|---------------|-------------------|
| Guest invite | Direct invite | Public registration link |
| RSVP flow | Guest-controlled | Host-approved |
| Ticketing | No | Yes |
| Audience | Private | Public or semi-public |

Registered Events are ideal for workshops, meetups, fundraisers, and any event where you want structured sign-ups rather than a personal invite list.
