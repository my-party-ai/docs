Event Links let you attach up to 3 external URLs to your event, each with a custom label. They appear on the event registration and invitation page so registrants can access them directly.

## Adding links

Links are added when you create or edit your event. For each link, enter:

- **Label** — a short name that tells attendees what the link is (e.g. "Directions", "Dress Code", "Event Website")
- **URL** — the full web address

You can add up to **3 links** per event.

## Where links appear

Once added, your links are displayed on the event registration page — the page attendees see when they open their invitation or ticket. They can tap or click any link directly from there.

## Common uses

| Link label | Use case |
|-----------|----------|
| **Directions** | Google Maps link to the venue |
| **Dress Code** | A page or PDF describing attire |
| **Event Website** | Your conference or event microsite |
| **Virtual Meeting** | Zoom, Google Meet, or Teams link for hybrid events |
| **Agenda PDF** | A downloadable version of the event programme |
| **Venue Website** | The venue's homepage or booking page |

<Tip>
  Use descriptive labels so attendees immediately know what they're clicking. "Venue Map" is clearer than "Link 1."
</Tip>
