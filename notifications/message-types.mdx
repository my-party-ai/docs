Fast Party keeps notifications to four types. Each has one job, so guests always know what a message means before they open it.

## At a glance

| Type | WhatsApp | Email | Push | In-app |
| --- | :---: | :---: | :---: | :---: |
| **Invitation** | ✓ | ✓ | ✓ | ✓ |
| **Confirmation** | ✓ | ✓ | ✓ | ✓ |
| **Update (immediate)** | ✓ | ✓ | ✓ | ✓ |
| **Update (digest)** | — | ✓ | — | ✓ |
| **Alert** | ✓ | ✓ | ✓ | ✓ |

Each person receives these on every channel they have: WhatsApp and email from their registration, and push if they use the Fast Party app. See [How notifications work](/notifications/overview).

## Invitation

**"You're invited."** The first message a guest gets about an event.

- Sent when you invite a guest by phone number or email, or to every member of a circle when a circle event goes live.
- Includes the event name, date, time, venue, who's hosting, and a **personal link** to the Event Page.
- Guests can RSVP from the link without downloading the app.

<Warning>
  Making a circle event live invites every member at once, and a notification can't be taken back. Check the venue, time and description before you set it live.
</Warning>

## Confirmation

**"You're in."** Sent every time someone responds.

- Covers **RSVPs**, **registrations** and **payments**. For a paid Registration Event, it includes the amount paid.
- Sent again whenever a guest changes their RSVP, so they always have the latest.
- For a Registration Event with approval required, the guest is told once they're approved, and then pays.

## Update

**News about the event.** Updates come in two forms.

<Tabs>
  <Tab title="Immediate">
    When a host posts on the [event wall](/notifications/event-wall) or sends an event broadcast, guests are notified **right away**.

    Use this when something can't wait until tomorrow: parking has moved, the schedule is up, photos are in.
  </Tab>
  <Tab title="Digest">
    Everything that changed on an event during the day is gathered into **one digest**, sent the **next morning**.

    For example, if you turn on Guest Preferences and add an Event Schedule after the invitations have gone out, guests get one message the next day covering both, instead of two separate interruptions.

    Digests go by **email** and **in-app**, never WhatsApp.
  </Tab>
</Tabs>

## Alert

**Something important has changed.** Alerts are kept separate from updates on purpose, so that when a guest sees an alert, they know it matters.

- Used for changes guests *must* know about: a new date or time, a change of venue, or a cancellation.
- Sent immediately, on every channel.
- Guests who haven't replied to the invitation yet still get alerts, even though they don't get the everyday updates.

<Tip>
  Keep alerts for real changes. If every post is an alert, guests stop paying attention to them.
</Tip>
