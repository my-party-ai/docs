Events are the foundation of Fast Party. Everything — guests, agendas, food preferences, potlucks, and tasks — is organised within an event.

<Note>
  Fast Party is designed for personal and social events — birthday parties, dinner parties, potlucks, holiday gatherings, work team events, and more.
</Note>

## Event types

When you create an event, you choose one of two types:

**Regular Event**

A standard private event. Invited guests receive a personal link and RSVP directly — accepted, declined, or maybe. You control who gets an invitation.

**Registered Event**

Guests must submit a registration request before they can RSVP. You review and approve (or decline) each registration before they're confirmed. Registered events require a capacity limit, and you can add ticket types, require payment, and set an age restriction.

<Tip>
  Use a Registered Event when you're hosting a larger gathering, a ticketed event, or anywhere you want to vet attendees before confirming their spot. See [Registered Events](/features/registered-events) for the full setup guide.
</Tip>

## Creating an event

Click **New Event** from your dashboard to create an event. You can fill in as much or as little as you like to start.

**Available fields:**

- **Event name** — required. Give it a clear name your guests will recognise.
- **Event type** — Regular Event or Registered Event (see above).
- **Date** — the date of the event.
- **Start time** — when the event begins.
- **End time** — when the event finishes.
- **Timezone** — defaults to the timezone set on your profile. Change it here if your event is in a different timezone.
- **Location** — optional. An address, venue name, or "TBD."
- **Hosted By** — optional. The name shown as the host on the invitation — useful when hosting on behalf of an organisation or group.
- **Expected guest count** — helps with planning food and seating.
- **Event description** — optional. A short note shown on the invitation.
- **Cover image** — optional. Personalise your event with a photo.
- **Co-hosts** — optional. Add co-hosts by name, email, and phone number. Co-hosts get access to manage the event alongside you.
- **Links** — optional. Add up to 3 external links (each with a label and URL) — useful for directions, dress code info, or a wedding website.
- **Registration capacity** — required for Registered Events. Choose from 50, 100, 250, 500, 1,000, or 1,000+.

You can also create events by talking to Antsy, Fast Party's AI concierge:

> "Create a birthday party for Saturday at 7 PM with 20 guests at my house."

Antsy fills in the details and creates the event for you.

## Event status

Every event has one of three statuses:

| Status | What it means |
|--------|--------------|
| **Draft** | You're still setting up. Nothing has been shared with guests yet. |
| **Confirmed** | The event is live. You can send invitations and guests can RSVP. |
| **Cancelled** | The event is off. Guests who were invited are notified automatically. |

## Editing an event

All event fields can be edited at any time from the event settings page. If you change the date or time after invitations have already been sent, Fast Party will offer to notify your guests of the update.

## Viewing your events

Your dashboard shows all upcoming events sorted by date. Past events move to your event history, where you can still view guest lists, agendas, and other details.

## Deleting an event

To delete an event, open event settings and select **Delete event**. If guests have already received invitations, they'll be notified that the event has been removed.

<Warning>
  Deleting an event is permanent. All guest data, agendas, tasks, and potluck information for that event will be removed.
</Warning>
