Every event you create in a circle is linked to it, and the whole circle is invited in one step. This is how a one-off becomes a series: a monthly book club, a weekly club night or an annual reunion, all with the same group.

## Plan the whole year in advance

A circle's events page works as its **calendar**. You can create every event for the year up front, from the spring meetup to the annual gala, and post them to the circle long before you're ready to invite anyone.

Members see what's coming, so they can save the dates. But they can only **view** these events: they can't open them or go to the Event Page. Each event opens to members only when you make it **live**, and that's the moment they're invited.

|  | Not live | Live |
| --- | --- | --- |
| **Members see it** | Yes, in the circle's upcoming events | Yes |
| **Members can open it** | No, view only | Yes, they go to the Event Page |
| **Members are invited** | No | Yes, everyone at once, on their own channels |
| **You can set it up** | Yes: details, template, tools | Yes |

This gives you time to set each event up properly, while members already know it's on the calendar.

## Manage Events

From the circle page, click **Manage Events**. This is the full list of the circle's events, including every upcoming event that isn't live yet.

- **Filter** by **All**, **Live**, **Not Live** or **Past**.
- **Switch view** between **Tile** and **Calendar** to see the year at a glance.
- **Set Reminder** on an event to nudge members.
- **Create Event** to add a new one, linked to the circle.

Members see the same upcoming events, but can't act on them until the organizer makes them live.

## Event types in a circle

| Type | In a circle |
| --- | --- |
| [**RSVP Event**](/private-events/event-creation) | Every member is invited and RSVPs. |
| [**Registration Event**](/public-events/overview) | Members sign up through the event's link, with or without your approval, and pay if the event is priced. |
| [**Open Event**](/events/open-events) | Every member is welcome, with no RSVP needed. Organization circles only. |

Like every event, a circle event can run over several days, with a different invitation template for each day. [Banner and templates →](/events/banner-and-templates)

## Make an event live

When an event is ready, make it **Live**. Every member of the circle is invited at once, on their own channels, and can open the Event Page to RSVP or register. [How notifications work →](/notifications/overview)

<Warning>
  Making an event live invites the whole circle, and a notification can't be taken back. Check the venue, time, description and invitation template first.
</Warning>

After an event is live, you can still invite people from outside the circle by sharing the link or adding them as guests. The circle is where the guest list starts, not where it has to end.

## Adding a circle to another event

When adding guests to any RSVP Event, click **Add from Circle** and choose a circle. All its members are added in one step. To leave someone out, remove them from that event's guest list; the circle itself doesn't change.
